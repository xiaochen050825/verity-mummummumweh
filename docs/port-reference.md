# Port comparison reference

Reference downloaded 2026-09-21 from the [UNECE publications page](https://unlocode.unece.org/publications/), production release 2025-1: [official archive](https://opensource.unicc.org/un/unece/uncefact/vocab-locode/-/jobs/artifacts/2025-1/download?job=package-release). Attribution: UNECE, CC BY 4.0. This is a bounded name dictionary, not the entire current directory or a guarantee of shipping-service coverage.

Corrections to the proposed patch: PLGDN is Gdansk; PLGDY is Gdynia. IDBUA is Bula; IDBUN is Buatan. In this reference CNSHA is Shanghai Hongqiao airport, CNSGH is Shanghai; CNNGB is Ningbo airport, CNNBO is Ningbo. JOAQB is a legacy entry marked for deletion in this release. We preserve declared source codes, never silently rewrite the originals.

The product compares SI against BL. A named-place difference remains a discrepancy even when both documents repeat the same incompatible code. Identical validated complete expressions can agree while also retaining a source code/name warning. That agreement does not certify geographic correctness. An unknown name plus a known code does not automatically pass. Slash-separated locations stay a complete expression rather than being collapsed to one selected port.

Company aliases and terminal qualifiers remain bounded application conventions. Unlisted or conflicting identities are not inferred from arbitrary five-letter text. The expanded dictionary is independently checked against source evidence in regression; expected answers are never loaded by the production engine.
