# Jev routing pilot — 21 September 2026

Scope: email classification only, first ten known participant emails (001–010). This is a small development pilot, not held-out validation, OCR accuracy, defect-detection accuracy, or a full 520-email benchmark. Ground truth was used after inference and never sent to either provider. No classification prompt or threshold was tuned to the ten labels.

| Measurement | Existing rules + Gemini | Rules + Jev + Gemini fallback |
|---|---:|---:|
| Categories matching supplied ground truth | 10/10 | 10/10 |
| Total serial classification time | 9.354 seconds | 9.389 seconds |
| Estimated API charge | US$0.00208875 | US$0.001302826 |
| Gemini calls | 8 | 4 |
| Jev calls | 0 | 8 |
| Zero-call invoice cases | 2 | 2 |

The final hybrid used Jev directly for four cases, the existing invoice rule for two, and Gemini for four uncertain cases. Classification costs were about 38% lower in this sample. Total latency was effectively unchanged; this test does not demonstrate a speed improvement.

An initial Jev-only probe proposed nine correct categories out of ten. All four uncertain decisions, including the incorrect proposal, were held for review. The independent Gemini fallback recovered these cases in the subsequent hybrid runs. Do not claim Jev alone reached 100% accuracy.

Models: TypeSafe `jev-1.13.0`; Grafilab `gemini/gemini-3.5-flash-lite`. Request times measured from one local Windows machine, serially, with no concurrent load. Gemini requests in this pilot capped output at 2,000 tokens. All measured calls returned HTTP 200. Pricing estimates use returned usage: Jev US$0.042/million input tokens, output free; Grafilab US$0.25/million input and US$2.25/million output. These are estimates, not reconciled invoices.

Total estimated charge for the initial probe, baseline, first hybrid and final hybrid: US$0.005047256, below the US$0.50 cap. Repeated calls used only the same ten emails.

Integration checks cover clear decisions, zero-call invoices, contradictory signals, malformed output, overload, unavailable fallback, incomplete messages and retention of review/failure states. Existing extraction, SI/BL pairing, seven-field rules and export behavior are unchanged.

Before broader claims: validate on additional authorized, unseen cases spanning all five categories; measure end-to-end defects, review rates, actual costs and latency across repeated runs. Do not extrapolate these ten emails to the entire dataset.
